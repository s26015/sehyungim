사용 가능한 기술

Python

Python을 이용하여 게임 개발과 인공지능 프로젝트를 제작하였다. 반복문과 함수, 클래스 등을 활용하여 프로그램 구조를 설계할 수 있다. 또한 알고리즘 문제 해결과 데이터 처리도 가능하며 다양한 라이브러리를 활용한 개발 경험이 있다.

Pygame

Pygame 라이브러리를 이용하여 테트리스와 같은 게임 프로젝트를 제작하였다. 키보드 입력 처리, 충돌 판정, 화면 출력 기능 등을 구현할 수 있으며 게임 루프 구조와 프레임 처리 방식에 대해서도 학습하였다.

HTML5 / CSS3

HTML5와 CSS3를 이용하여 다양한 웹 페이지를 제작할 수 있다. 시멘틱 태그를 활용하여 구조를 구성하고 CSS를 이용하여 디자인과 애니메이션을 적용할 수 있다. 또한 메뉴바와 이미지 스타일링, hover 효과 등을 구현할 수 있다.
